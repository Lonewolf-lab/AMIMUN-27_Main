    3. Create `src/components/providers/SmoothScrollProvider.tsx`:
       - Mark with `"use client"`.
       - Import `ReactLenis` from `lenis/react`.
       - Add `prefers-reduced-motion` check via `window.matchMedia("(prefers-reduced-motion: reduce)")`.
